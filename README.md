## Website Portfolio

This is a simple, self-contained static portfolio (plain HTML/CSS/JS).

### What to edit
1. Update your content in `index.html`:
   - Name/title in the hero
   - About text
   - Projects cards (title, description, links)
   - Contact email (see the `mailto:` section in the contact form JS)
2. Replace assets:
   - `assets/avatar.png` (optional)
   - `assets/Elias_Al_HADDAD_Resume.pdf` (this repo already links it as “Download CV”)

### Run locally
No build step is required.

Open `index.html` in your browser, or run a local static server (recommended) and browse to it.

Example (from this folder):
```bash
python3 -m http.server 5173
```

Then open: `http://localhost:5173`

### Hosting
- GitHub Pages / Netlify / Vercel (static) will work since there is no backend.
