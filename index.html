WealthWise 💰

AI-powered financial tools for young Canadians — built with Next.js 16, Claude Sonnet, and Tailwind CSS v4.

Overview

WealthWise is a full-stack web app built at the Claude Builders Hackathon @ McGill. It helps young Canadians take control of their finances through AI-powered transaction categorization, spending analysis, tax simulation, and wealth growth projections.

Event Claude Builders Hackathon @ McGill
Year 2025
AI Model Claude Sonnet (Anthropic SDK)

Tech Stack

Frontend

Next.js 16 React Tailwind CSS v4 shadcn/ui Recharts

Backend & AI

Anthropic SDK Next.js API Routes TypeScript

State & Parsing

Zustand PapaParse localStorage

Key Features

  • 🤖
    AI Categorization

    Claude automatically categorizes uploaded bank transactions by spending type.

  • 📊
    Spending Dashboard

    Interactive pie charts and overview cards break down expenses by category.

  • 💡
    AI Suggestions

    Claude analyzes spending patterns and generates personalized savings tips.

  • 📈
    Wealth Growth Projections

    Visualize long-term investment growth with compound interest modeling.

  • 🧾
    Canadian Tax Simulator

    Estimates federal & provincial income tax across all Canadian provinces.

  • 💬
    AI Financial Assistant

    Claude-powered chatbot answers questions about TFSAs, RRSPs, investing, taxes, and budgeting in real time.

Architecture Highlights

  • App Router with strict client/server separation — Claude API key never exposed to the browser.
  • Two API routes (/api/categorize and /api/suggestions) handle all Anthropic SDK calls server-side.
  • Global state via Zustand + persist middleware keeps transactions across sessions.
  • CSV bank statements parsed client-side with PapaParse; mock generator included for demo mode.
  • Tailwind CSS v4 configured entirely in CSS — no tailwind.config.ts needed.
